# Hunt Journal
This app ~~will help~~ helped you track your progress in the game Hunt: Showdown.

**Disclaimer**: At some point an update to Hunt removed the *function / side effect* that wrote the last games data to the `attributes.xml` file (or any other that I could find).
Since then, no new match data can be recorded.
This is why I disabled all recording functionality and uploaded a version of the app with my entire collected dataset as a showcase.

If you want a version of the code as used bevore, please refer to [`5567f71`](https://github.com/Excidion/hunt-showdown-journal/tree/5567f71eea200761cf2e6bd772c9636297c03d82)
